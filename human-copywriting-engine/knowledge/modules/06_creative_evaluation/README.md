# Module 06: Creative Evaluation

Menilai naskah dan konten affiliate secara kritis berdasarkan tujuh dimensi terpisah dan gerbang keakuratan wajib sebelum disetujui untuk dipakai.

## Prinsip Utama
1. Pisahkan skor kealamian bahasa, psikologi pembeli, persuasi, storytelling, adaptasi audiens, akurasi produk, dan autentisitas.
2. Skor persuasi tinggi tidak pernah boleh menutupi klaim palsu atau detail produk yang dikarang.
3. Setiap evaluasi wajib menghasilkan saran perbaikan konkret pada kalimat atau struktur yang lemah.
