# Template Prompt Gambar Storyboard (Adaptif Single / Multi-Sheet)

Gunakan template ini saat membuat `03-storyboard/storyboard.png` (untuk kampanye 4–8 panel yang masih terbaca jelas dalam 1 lembar) atau beberapa lembar berurutan `03-storyboard/storyboard-sheet-01.png`, `storyboard-sheet-02.png`, dst. (untuk 8–14+ panel agar tiap gambar tidak sempit atau buram).

- **Panduan Grid:**
  - `4` panel → `2×2` (1 lembar)
  - `6` panel → `2×3` atau `3×2` (1 lembar)
  - `8–12` panel → `2×4` atau pecah ke `2` lembar `2×3` (`Sheet 1: Panel 1–6`, `Sheet 2: Panel 7–12`)
  - `> 12` panel → pecah ke beberapa lembar berurutan (`4–6` panel per lembar) dengan penomoran panel menyambung

```text
Create a clean <K>-panel vertical commercial storyboard sheet (<Sheet X of Y, covering Panels A-B> in <grid layout, e.g. 2x3 grid>, each panel framed in 9:16 portrait aspect ratio) on a neutral dark-slate or clean white layout grid with thin borders.

[PRODUCT IDENTITY LOCK]: <Specific English Identity Descriptor + explicit component permanence list from 01-product-review/product-identity-lock.md matching the attached original reference image(s) — never a generic category description.>
[HAND & ENVIRONMENT LOCK]: Consistent natural Indonesian adult hand with <sleeve description>, inside <consistent room/lighting>.

Panel <A> — <STAGE / TIMING>: <Shot scale, camera angle, physical action, product position, small curved arrow showing camera/hand direction>.
Panel <A+1> — <STAGE / TIMING>: <Shot scale, macro/reveal/demo action matching storyboard pacing>.
...

Style: Realistic commercial photography/film storyboard frames, sharp focus, natural daylight, tiny numbered badges (<A>, <A+1>, ...) in top-left corners only. No paragraphs of text, no distorted typography, no comic speech bubbles, no watermarks.
```
